# CatFrame Compat

The mod compatibility layer for CatFrame, also provide some useful tools for mod develop.

# Compact
## 1. IME Compact.

- IngameIME compact: For all of the text input box components let it input CJK
- IMEBackport: Same as IngameIME.

## 2. MCPatcher Compact

- MCPatcherForge series (Except MCPatcherForge), e.g., NotFine, angelica, optifuture: Suppport CTM methods to let it working on the json-modelized blocks.
- MCPatcherForge (optifutrue <= 1.2.3): hence have 8 paramaters
